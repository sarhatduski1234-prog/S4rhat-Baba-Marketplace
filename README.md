# S4rhat-Baba-Marketplace
sarhatstore - منصة تسوق عربية متعددة البائعين

## الموقع

واجهة متجر عربية ثابتة تعمل مباشرة من `index.html`، وتشمل البحث والتصنيفات وسلة مشتريات محفوظة على الجهاز. الأسعار والصور والمنتجات المعروضة أمثلة توضيحية؛ هذا الإصدار لا يتضمن حسابات البائعين أو الدفع أو الشحن.

## النشر على GitHub Pages

يُنشر الموقع تلقائيًا عند الدفع إلى فرع `main` عبر سير العمل الموجود في `.github/workflows/pages.yml`.

1. من إعدادات المستودع، افتح **Settings → Pages**.
2. اختر **GitHub Actions** كمصدر للنشر.
3. ادفع التغييرات إلى `main`، ثم راجع حالة سير العمل في تبويب **Actions**.
4. بعد نجاح النشر، سيكون الموقع على `https://sarhatduski1234-prog.github.io/S4rhat-Baba-Marketplace/`.

يمكن فتح `index.html` مباشرةً للمعاينة؛ بعض ميزات المتصفح مثل نسخ قائمة المشتريات تتطلب الموقع عبر HTTPS.
